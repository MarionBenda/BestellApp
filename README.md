# 🍕 Bestellapp – Food Delivery Application

A dynamic, responsive food ordering application inspired by platforms like Lieferando. This application was developed as my **second official practical project during my Full-Stack Developer apprenticeship**

---

## 🎯 Project Overview & Context

Following my first project (Fotogram), this application marks a major step forward in my software engineering training. Developed at **DA München**, the goal was to build a complex, state-driven user interface using vanilla web technologies. It simulates a complete food delivery checkout flow, focusing on interactive state management (shopping cart calculation) and responsive user interfaces.

---

## ✨ Features

- **Menu Selection:** Browse through a variety of dishes with structured categories and pricing.
- **Dynamic Shopping Cart:** Add, remove, or adjust the quantity of items with real-time price updates.
- **Delivery vs. Pickup Toggle:** Dynamic calculation of delivery fees depending on the user's fulfillment choice.
- **Interactive Order Button:** Submits the order and triggers a clear, user-friendly order confirmation message detailing the purchase.
- **Responsive Layout:** Optimized for mobile phones (ordering on the go), tablets, and desktop devices.

---

## 🛠️ Tech Stack & Concepts

To deepen my understanding of fundamental software engineering patterns, this project is built completely with native web technologies:

- **HTML5:** Semantic structure for menus, checkout forms, and shopping cart layouts.
- **CSS3:** Modern layouts using Flexbox and Grid, custom variables, and responsive media queries.
- **Vanilla JavaScript:**
  - **State Management:** Tracking cart items, quantities, and totals dynamically in memory.
  - **DOM Manipulation:** Rendering cart updates instantly without page reloads.
  - **Conditional Logic:** Dynamically adding/removing delivery fees based on user selection.
---

## 📈 Learning Progress & Evolution

- **Advanced State Management:** Moving from simple DOM updates (as seen in Fotogram) to managing complex data arrays representing a real-time shopping cart.
- **Best Practices:** Transitioned to **writing all commit messages in English** to adapt to international development workflows and professional standards.
- **UX/UI Design:** Implementing logical user flows, such as disabling the order button when the cart is empty or dynamically updating delivery conditions.
